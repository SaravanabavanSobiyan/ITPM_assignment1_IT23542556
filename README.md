# ITPM Assignment 1 – Thanglish to Tamil Translator Testing

This repository contains Playwright automated tests created for ITPM Assignment 1.

## Application Tested
https://tamil.changathi.com/

## Test Types Covered
- Positive functional tests
- Negative functional tests
- UI real-time conversion test
- Mixed language inputs
- Formatting and punctuation cases
- Short, medium, and long inputs

## Tools Used
- Playwright
- JavaScript
- Node.js

## How to Run Tests

Install dependencies:

npm install

Install browsers:

npx playwright install

Run tests:

npx playwright test

Run with visible browser:

npx playwright test --headed
